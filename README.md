# Healthcare-Emergency-Department-Analytics-Dashboard

An interactive **Healthcare Emergency Department Analytics Dashboard** developed using **Power BI** to analyze emergency department performance, patient demographics, operational efficiency, and patient satisfaction. This dashboard transforms raw healthcare data into meaningful insights that support data-driven decision-making for hospital administrators and healthcare professionals.

---

## 📌 Project Overview

Emergency Departments (ED) handle thousands of patient visits, making it essential to monitor operational performance through data analytics. This project demonstrates how Power BI can be used to visualize key healthcare metrics and identify trends that help improve patient care and optimize hospital operations.

The dashboard enables healthcare professionals to:

- Monitor patient volume and operational trends.
- Analyze patient wait times and satisfaction levels.
- Track admission and referral patterns.
- Identify peak patient arrival periods.
- Support data-driven resource planning and decision-making.

---

## 🎯 Business Objective

The objective of this project is to provide a centralized dashboard that helps healthcare organizations:

- Improve Emergency Department operational efficiency.
